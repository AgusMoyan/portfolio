## Agent skills

### Issue tracker

Issues locales en markdown bajo `.scratch/<feature>/` (ignorado por git). See `docs/agents/issue-tracker.md`.

### Triage labels

Vocabulario por defecto (needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix), como línea `Status:` en cada ticket. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` + `docs/adr/` en la raíz (se crean bajo demanda). See `docs/agents/domain.md`.
